## Telethon: идеи для расширения API

## Выполнено в проекте

### Авторизация и базовые функции
- [x] Авторизация по номеру телефона (`/auth/login`, `/auth/verify`, `/auth/password`)
- [x] Авторизация через QR-код (`/auth/qr/generate`, `/auth/qr/status`, `/auth/qr/image`)
- [x] Получение списка чатов (`/chats`)
- [x] Получение списка папок чатов (`/chats/folders`)
- [x] Получение чатов из конкретной папки (`/chats/folder`)

### Сообщения и медиа
- [x] Отправка текстовых сообщений (`/messages/send`)
- [x] Получение истории сообщений из чата (`/messages`)
- [x] Получение расширенной информации о сообщениях (id, sender_id, date, media_type, media_id)
- [x] Скачивание медиафайлов из сообщений (`/messages/media`)

### 1. Работа с медиафайлами
- Отправка фото, видео, аудио, документов  
- [x] Скачивание медиафайлов  
- Отправка голосовых сообщений  
- Отправка стикеров и GIF  
- Отправка геолокации и контактов  

### 2. Работа с сообщениями
- [x] Получение истории сообщений из чата  
- [x] Редактирование сообщений (`/messages/edit`, `PATCH`)  
- [x] Удаление сообщений (для себя / для всех) (`/messages/delete`, `DELETE`)  
- [x] Пересылка сообщений (`/messages/forward`, `POST`)  
- [x] Ответ на сообщения (reply) (`/messages/reply`, `POST`)  
- [x] Реакции на сообщения (`/messages/reaction`, `POST`)  
- [x] Поиск по сообщениям (`/messages/search`, `POST`)  
- [x] Получение подробной информации о сообщении  

### 3. Работа с чатами и каналами
- Создание групп и каналов  
- Приглашение пользователей в группу  
- Исключение пользователей из группы  
- Получение участников группы / канала  
- Получение списка администраторов  
- Изменение прав участников  
- Получение информации о чате (описание, фото, настройки)  
- Изменение названия и описания чата  
- Установка фото чата  

### 4. Работа с пользователями
- Получение информации о пользователе  
- Блокировка / разблокировка пользователей  
- Получение списка контактов  
- Добавление / удаление контактов  
- Получение статуса пользователя (онлайн, последний раз в сети)  

### 5. Работа с каналами
- Подписка на канал  
- Отписка от канала  
- Получение постов из канала  
- Публикация постов в канал  
- Редактирование постов  
- Удаление постов  
- Получение статистики канала (для администраторов)  

### 6. Работа с ботами
- Отправка команд боту  
- Работа с inline‑кнопками  
- Обработка callback‑запросов  

### 7. Продвинутые функции
- [x] Работа с папками чатов (folders)  
- [x] Закрепление / открепление сообщений (`/messages/pin`, `POST`)  
- [x] Отметка сообщений как прочитанных (`/messages/read`, `POST`)  
- [x] Архивирование чатов (`/chats/archive`, `POST`)  
- Получение уведомлений о новых сообщениях (event handlers) — не реализовано через REST: нужен постоянный канал доставки (WebSocket/SSE/long polling), а не одноразовый HTTP-запрос.  
- [x] Фильтрация сообщений по типу (текст, медиа, сервисные и т.д.) (`/messages/filter`, `POST`)  
- Работа с форвардами  
- Получение истории редактирования сообщения  

### 8. Управление аккаунтом
- Изменение имени и фамилии  
- Изменение `username`  
- Изменение биографии (about)  
- Изменение фото профиля  
- Получение информации о своём аккаунте  
- Управление сессиями (отключение других устройств)  

### 9. Работа с файлами
- Загрузка файлов на серверы Telegram  
- [x] Скачивание файлов с серверов Telegram  
- Работа с большими файлами (chunked upload)  

### 10. События и уведомления
- Обработка новых сообщений в реальном времени  
- Обработка редактирования сообщений  
- Обработка удаления сообщений  
- Отслеживание новых участников в группах  
- Отслеживание изменений в чатах (смена названия, аватарки, прав и т.д.)  

### Что можно реализовать в первую очередь
- Отправка медиафайлов (фото, видео, документы)  
- Получение истории сообщений  
- Редактирование и удаление сообщений  
- Работа с группами (приглашение / исключение участников)  
- Обработка событий в реальном времени (listeners / event handlers)
