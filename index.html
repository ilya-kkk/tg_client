Telegram REST API / SaaS над Telethon

Это REST API поверх Telethon для работы с обычными аккаунтами Telegram, а не только с ботами. Проект закрывает типовые интеграционные задачи для автоматизаций и внешних систем через понятные HTTP-эндпоинты.

Уже сейчас поддерживается авторизация по номеру телефона с обработкой 2FA, что позволяет безопасно подключать реальные пользовательские аккаунты к API-слою.

В дальнейшем проект будет развиваться в мультиаккаунтный SaaS: хранение сессий в Supabase, централизованное управление несколькими аккаунтами и расширенные сценарии администрирования.

Возможности

  • Авторизация по номеру телефона + 2FA.
  • Авторизация через QR-код.
  • Получение списка чатов и папок.
  • Отправка сообщений, медиа, голосовых, стикеров, геопозиций и контактов.
  • Управление чатами и каналами (создание, инвайты, кик, архивирование, закрепы, реакции).
  • Работа с пользователями и контактами (инфа, блокировка, контакты, статус).
  • Управление аккаунтом (username, имя, about, фото, сброс сессий).

Технологии

  • FastAPI
  • Telethon
  • PostgreSQL / Supabase (для хранения сессий)
  • Docker / docker-compose

Планы по SaaS

  • Мультиаккаунт через Supabase (telegram_sessions).
  • Панель управления сессиями и аккаунтами.
  • Интеграция с n8n для автоматизаций.
API-документация: /docs (Swagger UI)
Запуск локально: uvicorn app.main:app --reload
