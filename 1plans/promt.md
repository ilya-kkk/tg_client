## Контекст проекта

**Backend:** FastAPI (Python), запущен на `http://localhost:8000`. Все Telegram-операции идут через него.

**Frontend:** Next.js 14 (App Router), TypeScript, папка `FrontEnd/`. Страницы Dashboard находятся в `FrontEnd/app/(dashboard)/`.

**Ключевые API-эндпоинты:**
- `GET /sessions` → список сессий (поле `sessions`, каждая содержит `session_id`, `phone`, `is_authorized`)
- `GET /sessions/{session_id}/account/me` → информация об аккаунте (`first_name`, `last_name`, `username`, `phone`, `photo`)
- `POST /sessions/{session_id}/auth/login` body: `{ "phone": "+7..." }` → отправить код (ответ: `{ success, message }`)
- `POST /sessions/{session_id}/auth/verify` body: `{ "phone": "+7...", "code": "12345" }` → подтвердить код (ответ: `{ success, password_required, message }`)
- `POST /sessions/{session_id}/auth/password` body: `{ "password": "..." }` → ввести 2FA пароль (ответ: `{ success, message }`)
